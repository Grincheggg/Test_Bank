**В видео будут показаны тесты по:**

1. Созданию нового пользователя (позитивные и негативные)

2. Авторизации пользователя (позитивный и негативный для админа и юзера)

3. Созданию банковского счета пользователем (позитивный и негативный(негативный админ не может создать себе счет)

4. Добавлению Allure-отчетности

**Практика по API-тестам**

**По аналогии с видео вы пишите тесты для:**

5. Пополнения банковского счета (/deposit) ( сделал позитивный, и негативный ( негативный заключается в превышение лимита)

6. Перевода средств между банковскими счетами (/transfer) (есть позитивный и негативный)

7. Запроса на получение кредита (/credit/request) ( тоже есть, обнаружен баг с бэком, при негативном тесте неправильный ответ от сервера)

8. Погашения кредита (/credit/repay) (есть, прописан позитивный и негативный)

9. Добавления Allure-отчетности в фреймворк, по аналогии с видео, к методам, которые реализуете самостоятельно

Для каждой ручки (те, что указаны выше) достаточно написать один позитивный автотест и один негативный
